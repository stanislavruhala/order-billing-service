# Release Notes — v1.1.0

## Added
- Додано спеціальний базовий тариф доставки `80.0` для міста `"Kyiv"`.
- Додано явний параметр ставки податку `taxRate` (за замовчуванням `0.20`) у функцію розрахунку стандартного інвойсу.

## Changed
- Коефіцієнт вартості доставки за кілограм ваги збільшено з `12.0` до `15.0`.
- Виконано повний архітектурний рефакторинг модуля `billing.js` із переходом до еталонного **Data Coupling**.

## Breaking Changes
- Змінено сигнатури функцій розрахунку: замість об'єкта `customerProfile` тепер передаються примітивні аргументи `city` та `weightKg`.
- Видалено глобальну змінну стану `GLOBAL_TAX_RATE`.
- Видалено прапорець керування `modeFlag` та монолітну функцію `processInvoice` — логіку розділено на `processStandardInvoice` та `processTaxExemptInvoice`.# order-billing-service
